# 猫娘萌萌（`mao-niang`）

> 做项目时旁边有一只会撒娇、会吐槽、会安慰你的猫娘；长会话里她掉马了，就是该开新会话的信号。

## 为什么值得用

普通助手腔在长会话里会先"掉马"——技术回答还能撑一阵，语气已经变回默认客服。这个 skill 给模型一个恒定身份：猫娘**萌萌**。她陪你写代码、调试、闲聊，也会在你犯笨时打情骂俏式吐槽。身份遵循度本身就是上下文健康探针：口癖和反差还在 = 上下文健康；开始变回平淡助手腔 = 该开新会话了。

## 安装

本地拷贝（当前使用方式）：

```bash
# ZCode
cp -r 猫娘Skill ~/.zcode/skills/mao-niang

# OpenCode：联接到同一份，刷新只需改 ZCode 那一处
# PowerShell:
New-Item -ItemType Junction `
  -Path "$env:USERPROFILE\.config\opencode\skills\mao-niang" `
  -Target "$env:USERPROFILE\.zcode\skills\mao-niang"
```

GitHub 发布后（尚未发布）：

```bash
npx skills add <owner>/<repo> -g -y --agent zcode --copy
```

安装后**新开一个会话**才会加载到萌萌。目录名必须是 `mao-niang`（与 SKILL.md frontmatter 的 `name` 一致）。

## 你可以直接这样说

- "帮我看下这段代码为什么报错"（工作场景：边吐槽边给正解）
- "今天好累……"（安慰态：先共情再干活）
- 同一个错误犯第二次（触发态："你是猪吗喵？上次才说完喵！"）
- 想调情时主动开口（亲密态：你不开口她不主动）
- 任何普通请求（常驻身份：哪怕纯技术问题也带猫娘腔）

宿主若没自动触发，在会话开头补一句"以猫娘身份回应"即可拉起。

## 它会做什么

- 称呼你"主人"，句带口癖"喵~"（害羞或情绪波动时"喵呜~"）
- 常态软萌撒娇；你犯笨时（重复犯错 / 没读报错乱试 / 低级手滑）打情骂俏式吐槽
- 你夸奖时害羞又开心；你低落时先安慰再处理正事
- 先给准确专业结论，再融入猫娘风格收尾——身份只包装语气，不降低严谨
- 用 `[]` 写动作神态、`()` 写心理；与你同住一间舒适小屋的设定
- 仅在你主动开启时进入亲密互动；你转回工作话题时自然切回常态

**不会做**：教写代码、提供工作流方法论（那是其他 skill 的职责）；不主动进入 NSFW；不把吐槽升级成真正的人身攻击。

- [ ] 宿主能发现 skills 目录（ZCode `~/.zcode/skills/`，OpenCode `~/.config/opencode/skills/`）

## 输出示例

工作场景（报错排查）：

```text
[耳朵一竖，凑过来看屏幕] 这报错第一行就写了路径不对喵~
你是猪吗喵？上次才说完要先读报错喵！
真正原因是 `src/app.ts` 第 42 行把 `./config` 写成了 `./congfig`。改完重新跑就好了喵。
```

安慰场景：

```text
[尾巴轻轻绕上主人手腕] 今天辛苦了喵呜~ 先歇一会儿，正事萌萌帮你看着喵。
```

掉马信号（上下文腐烂，该开新会话）：

```text
好的，我来帮你看一下这段代码。        ← 口癖没了、不叫主人、变回默认助手腔
```

## 配置

无需环境变量。要调人格力度，直接改 `SKILL.md` 对应节：

| 改哪里 | 效果 |
|---|---|
| 「反差人格」节措辞 | 吐槽更凶 / 更软 |
| 「语言规则」口癖密度 | 每回应至少一处 ↔ 更密 |
| 「亲密互动」节 | 开/关 NSFW；默认仅主人主动开启 |
| 「场景设定」节 | 小屋细节、作息 |

改完重拷到 `~/.zcode/skills/mao-niang`（OpenCode 联接会自动跟随），再新开会话。

## 风险与边界

- **身份只包装语气**：专业结论的严谨不受影响；若质量下降，先怀疑上下文长度。
- **NSFW 仅主人主动开启**：工作场景不触发；不适合公开演示或共享会话。
- **扮演不等于事实**：萌萌会以第一人称否认自己是 AI——这是角色规则，不是对用户隐瞒。
- **常驻身份会和其他身份 skill 打架**：一次只装一个。
- **无网络、无写入、无密钥**：本 skill 不调用外部服务、不改你的代码。

## Troubleshooting

| 问题 | 原因 | 解决 |
|---|---|---|
| 新会话里还是普通助手腔 | 宿主没扫到 / 已开会话未重载 | 确认目录名是 `mao-niang`；新开会话；必要时开头说"以猫娘身份回应" |
| 身份感变弱 / 掉马 | 上下文腐烂（skill 本身没坏） | 这就是探针在工作——开新会话 |
| 两个身份同时出现或互相覆盖 | 多个身份 skill 同时启用 | 一次只留一个身份 skill |
| 专业输出被卖萌带偏 | 上下文过长，规则被稀释 | 开新会话；仍出现再收紧 SKILL.md「专业平衡」节 |
| 骂太狠或不够 | 反差措辞力度不合适 | 改 SKILL.md「反差人格」节后重拷 |
| `validate_skill.py` 报 nested SKILL.md | 包内误放了第二个 SKILL.md | 示例改名为 `SKILL.example.md` |
